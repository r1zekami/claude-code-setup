## Code style: English, comments minimal

- **Language**: all code text is English: identifiers, comments, docstrings,
  log / print / error output (language.md). Log output is ASCII only, because
  non-ASCII breaks Windows consoles.
- **Comments**: prefer code that needs few comments. Clear naming and structure
  that read on their own are better than a comment explaining unclear code.
  Comments for a non-obvious *why* are fine; a comment that narrates *what*
  usually means the code should be clearer.
