## Code style: English, comments minimal

- **Language** — all code text is English: identifiers, comments, docstrings,
  log / print / error output (language.md). Log output is ASCII only — non-ASCII
  breaks Windows consoles.
- **Comments** — prefer code that needs few comments in the first place: clear
  naming and structure that read on their own beat a comment explaining what
  unclear code does. Comments for a genuinely non-obvious *why* are fine;
  comments narrating *what* usually mean the code should be clearer instead.
